ChatGraphic 是 AI 编程 CLI 的配套可视化工具：对话进行中，每轮结束自动解析出 方案、最终选择、任务、决策、文件变更，长成一张会话导图。 聊完即得图，讨论不迷路，成果可沉淀。

轮次级 Hook 触发，不阻塞对话 同链路解析（各走各的模型/认证） 自动增量，成本近似常数 存储渲染全程本地 导出 PNG / Markdown

What

一张导图，长在对话里

每一轮对话结束，新内容自动并入导图：讨论过的方案、被拍板的最终选择、拆出的任务、留下的决策、改过的文件——低置信内容进「待确认」，绝不编造。

Integrations

三端接入，各走各的链路

三个 CLI 各有原生的事件机制，ChatGraphic 各取所长；解析引擎按转录来源路由——用哪个 CLI 聊天，就用哪个 CLI 的模型与认证解析，互不依赖。

Codely扩展 / 克隆

触发：AfterAgent Hook（每轮结束） · 引擎：codely -p · 注册作用域跟随安装位置（--scope workspace 即项目级）

codely extensions install https://github.com/weiwei-gu/ChatGraphic --scope workspace node .codely-cli/extensions/chatgraphic/chatgraphic/install.js

Codex CLInotify

触发：agent-turn-complete（notify 机制） · 引擎：codex exec · 注册为用户级全局（notify 仅在用户级配置生效，已实测）

node chatgraphic/install-codex.js # 写入 ~/.codex/config.toml

Claude CodeStop Hook

触发：Stop 事件（每轮响应结束，stdin JSON） · 引擎：claude -p · 注册为用户级全局（与既有 Hook 并存）

node chatgraphic/install-claude.js # 写入 ~/.claude/settings.json
How it works

Hook 驱动，同链路同边界

Hook 触发，秒级退出

每轮结束事件（AfterAgent / notify / Stop）拉起对应触发器：转录去重、未完成旧解析最新胜出，毫秒级退出，绝不阻塞对话。

精简 + 同链路解析

转录归一化（三端格式容错）→ 精简 → 按来源路由到该 CLI 的无头模式解析。三问准入 + 置信分级，寒暄与噪声不上图。

本地出图，实时生长

graph.json 会话级隔离、版本递增，增量解析只发「图状态 + 新增轮次」；viewer 生长动画、节点回链原文、导出 PNG / Markdown。

Quick start

快速开始

git clone https://github.com/weiwei-gu/ChatGraphic.git cd ChatGraphic node chatgraphic/install.js # Codely：Hook 注册（作用域跟随安装位置） node chatgraphic/install-codex.js # Codex：写入 ~/.codex/config.toml node chatgraphic/install-claude.js # Claude Code：写入 ~/.claude/settings.json node chatgraphic/serve.js # 打开导图视图（http://localhost:4830）

之后正常用任意 CLI 聊天——每轮结束，导图自动生长。安装细节、作用域对比与复盘补跑见 docs/guide.md。

Why ChatGraphic

为什么需要它

AI 编程工具解决了「写代码」，但没有解决「讨论的沉淀」——长对话里，最有价值的结论最容易丢。

  • ✕对话太长，找结论靠翻记录。一次会话动辄几十上百轮，「刚才说好的方案」回头要翻很久。
  • ✕方案讨论没有落点。A/B 方案的取舍埋在对话流里，事后说不清「当时为什么这么定」。
  • ✕任务状态靠脑子记。AI 记得上下文，人记不全——做完了什么、还剩什么，全凭翻聊天记录。
  • ✕有价值的讨论无法沉淀。方案与决策随会话结束而消失，进不了文档、周报和评审材料。
产品方案

会话，即导图

导图从第一句对话起笔：讨论过的方案自动成为分支，最终选定的方案高亮标记， 选定方案之下再展开对应任务；对话继续，导图实时生长；一键导出，成果可存、可查、可分享。

你和 AI 讨论过的一切，都长在同一张图上。

自动解析实时生长一图沉淀
Core Features

核心功能

围绕「接入 — 实时生长 — 微调 — 沉淀」四个环节，覆盖 AI 会话可视化的完整链路。

会话智能解析

读取 Codely 的本地会话，从第一句对话开始识别方案、最终选择与对应任务。

实时生成导图

对话进行中导图实时生长，无需等会话结束，也无需手动触发。

增量同步

只解析新增的对话轮次，秒级上图，上百轮的长会话也不卡顿。

可编辑可标注

AI 生成的节点支持手动调整、增删与备注，人机协作把导图打磨到位。

多格式导出

PNG / SVG / Markdown / OPML，直接贴进周报、README 与评审材料。

本地优先

会话在本地解析、本地渲染，代码与讨论不出本机，离线可用，可私有化。

Roadmap

阶段规划（拟定）

先把「边聊边长」的核心体验做扎实，再扩展集成与协作，每阶段独立可用。

Phase 1
2026 Q4

MVP · 边聊边长

  • Codely 会话实时监听（Hook / 文件监听）
  • 方案 / 最终选择 / 任务实时上图
  • CLI + PNG / Markdown 导出
Phase 2
2027 Q1

集成 · 深度协同

  • 历史会话补解析（安装前的对话也能出图）

Phase 3
2027 Q2+

生态 · 协作沉淀

  • 对话回退：节点状态同步重置（导图版本回滚）
  • 多会话合并导图与项目视图
  • 团队空间与分享链接
  • IDE 插件 · 企业私有化部署

* 排期为拟定建议，以评审结论为准。
